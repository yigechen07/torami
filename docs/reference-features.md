# 抖音参考视频功能对照

参考：凉凉最爱4536《试着在电脑上养一只兔岚咪～》

- 分享地址：https://v.douyin.com/mOPKjBU6jVY/
- 视频：https://www.douyin.com/video/7699216927968808243
- 时长约 48 秒。按实际画面和右键菜单实现，没有使用作者的角色帧序列或程序。

| 参考内容 | 本版入口与行为 |
| --- | --- |
| 0–4 秒：坐着卖萌、眨眼 | 待机呼吸与眨眼；触发行为 → 坐下 |
| 5–10 秒、约 36 秒：长耳朵遮眼害羞 | 害羞，用耳朵遮眼睛；自动巡逻时也会偶尔触发 |
| 11–18 秒：巡逻领地 | 自动巡逻开关，走路、转向、坐下、摇摆和害羞 |
| 20–24 秒：拖到音乐窗口顶边后跳回桌面 | 脚靠近窗口顶边松手后，沿顶边走到边缘再跳回；窗口移动时跟随，消失后下落 |
| 29–31 秒：跟随鼠标 | 沿当前屏幕底边追随鼠标的横向位置 |
| 窗口归还 | 恢复主动推过的窗口；额外提供“轻轻推一下脚下窗口”入口，需辅助功能权限 |
| 显示统计信息 | 单只的时长、摸摸次数、拎起次数、移动距离、数量和站立位置 |
| 坐下并面向鼠标 | 保持坐姿，向鼠标所在方向转身 |
| 坐下 | 保持坐姿，不自动巡逻 |
| 坐下并摇摆 | 保持坐姿，左右摇摆 |
| 暂停动画 | 暂停所有宠物的物理、行为计时、CSS 动画和音频，继续后恢复 |
| 去除、仅剩一个、仅剩该类型 | 移走当前宠物、保留当前宠物；只有一种角色时，类型过滤不可用 |
| 关闭程序 | 退出并尝试归还被推过的窗口 |
| 末尾：持续拖动把玩、下落表情 | 拖拽、甩抛、重力、弹跳、落地压缩与惊讶嘴型 |

视频画面上方裁掉的菜单项无法确认；本版提供手动增加桌宠，最多五只。未把窗口攀爬、天花板倒挂等未在视频中确认的行为算作演示功能。Yuha 原声生气动作来自用户之前指定的另一个参考。

Mac 窗口顶边需有足够空间容纳整只兔岚咪；被其他窗口完全遮住的顶边不参与碰撞。全屏窗口的顶边通常没有足够空间。窗口互动只读窗口边界，不采集图像或标题。

## 0.4 菜单整理

原有功能收进“互动”“陪伴方式”和“设置”中；一级菜单共七项。没有作用的单一角色类型筛选已移去。语言入口始终标为“语言 / 언어”，方便从韩语切回中文。新增默认开启的全屏自动隐藏规则，退出全屏后恢复，保持用户手动隐藏的选择。
